Why localhost links failed

127.0.0.1 only works on the computer running the server. The build sandbox is not your phone. This portal is the public entry point; the API is started with the commands below.

Get a phone-reachable URL (fastest)

git clone https://github.com/doitupsolutions810-crow/control12-workspace.git
export ALLOW_AGENT_EXECUTION=true
./run.sh   # or scripts/deploy.sh process

npx localtunnel --port 8080
# or: cloudflared tunnel --url http://localhost:8080
# or: ngrok http 8080

Open the https URL the tunnel prints on your phone.

VPS public IP

cd c12-ship
export ALLOW_AGENT_EXECUTION=true
export CONTROL12_API_TOKEN=$(openssl rand -hex 32)
./run.sh
# open http://YOUR_VPS_IP:8080/
